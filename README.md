# South Indian Wedding Invitation

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

Edit:

`src/lib/weddingData.ts`

Replace:
- bride/groom names
- photos
- date/time
- events
- venue + Google Maps
- family names
- WhatsApp links
- music path
- Telugu messages

Put your files here:

- `public/images/bride.jpg`
- `public/images/groom.jpg`
- `public/images/photo1.jpg` ... `photo6.jpg`
- `public/audio/wedding-music.mp3`

## Notes

The project has image fallbacks so it remains visually usable before you add your own photos.

For production, use a properly licensed wedding instrumental for the music file.
